# How this site is built

The HTML pages are generated by `gen.py` from shared content (header, footer, program details, structured data).

To rebuild after editing `gen.py` or `style.css`:

```
DOMAIN=https://ishayogapallipalayam.github.io python3 _source/gen.py .
```

Update the program dates in `gen.py` (EVENT and EVENT_BLOCK) after each program.
